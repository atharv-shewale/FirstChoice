# FirstChoice Digital - Landing Page

A premium, modern, and high-converting landing page for **FirstChoice Digital**, a web development agency empowering small businesses, local shops, restaurants, and startups across Maharashtra (Kolhapur, Pune, and Mumbai).

![FirstChoice Digital Mockup](firstchoice_digital_mockup.jpg)

## ⚡ Tech Stack & Design Features

- **Cyber Obsidian & Dark Navy Aesthetic**: Minimalist black (`#05070D`) and dark navy background with glowing electric-blue and cyan accents.
- **3D Perspective Showcase**: CSS 3D transformed interactive mockup displaying desktop and mobile interfaces with real-time analytics badges.
- **Local Trust Indicators**: Dedicated regional badges for Kolhapur (Laxmi Road, MIDC), Pune (FC Road, Baner, Hinjawadi), and Mumbai (Bandra, Andheri).
- **Core Services Grid**: 3-column layout highlighting E-commerce Stores (UPI & WhatsApp notifications), Business Websites (Google Maps & local SEO), and High-converting Landing Pages.
- **Interactive WhatsApp Quote Modal**: Seamless quote generator that prefills a direct WhatsApp message for zero-friction client conversion.
- **Floating Live Support Badge**: Always accessible 1-tap WhatsApp consultation.
- **Tailwind CSS & Lucide Icons**: Ultra-fast, lightweight, responsive on all devices.
